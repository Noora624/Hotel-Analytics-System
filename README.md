# Hotel / Resort Analytics System

## Project Overview

This project focuses on analyzing hotel booking data to generate business insights related to booking trends, cancellations, customer behavior, ADR (Average Daily Rate), revenue performance, and operational analytics.

The analysis was performed using Python, SQL, Pandas, SQLite, and data visualization libraries.

---

## Objectives

* Analyze hotel booking patterns
* Understand cancellation behavior
* Compare Resort Hotel and City Hotel performance
* Study monthly booking trends
* Analyze ADR (Average Daily Rate)
* Perform SQL-based business analysis
* Create professional visualizations for decision making

---

## Dataset Used

Hotel Booking Demand Dataset from Kaggle.

Dataset includes:

* Hotel type
* Booking details
* ADR
* Customer country

* Cancellation information
* Lead time

* Stay duration

## Key Insights

* August recorded the highest bookings
* January recorded the lowest bookings
* City Hotels showed higher cancellation rates
* Resort Hotels had lower cancellation percentages
* Majority of ADR values were concentrated below 200
* Portugal (PRT) generated the highest bookings
